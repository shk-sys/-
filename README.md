# 🚐 마이트립(My Trip) - 동화형 자아탐색 여행 웹앱

'마이트립(My Trip)'은 다문화 및 중도입국 청소년이 노란 캠핑카를 타고 요정 모아와 함께 5개의 마을을 여행하며 **스스로 '내가 이만큼이나 해냈구나!'라는 성취감과 성장의 기쁨**을 느끼도록 돕는 동화형 자아탐색 웹앱입니다.

---

## 🌟 핵심 기획 의도 및 특징

- **평가나 관리가 아닌 '청소년 스스로의 성취감'**:
  - 마이트립은 청소년을 평가하거나 감독하는 앱이 아닙니다.
  - 질문 하나하나를 완료해 갈 때마다 찍히는 **완료 도장**, **마을별 완료 개수**, **전체 여정 진행률 바**, 그리고 **요정 모아의 성장 모습**을 보며 자신의 성장을 시각적으로 체감합니다.
- **철저한 사생활 보호 (기기 내 저장)**:
  - 복잡한 서버나 외부 데이터베이스를 사용하지 않고, 오직 **청소년 각자의 스마트폰/태블릿 기기(localStorage)**에만 안전하게 보관됩니다.
  - 질문에 대한 답변은 앱에 입력하지 않고 **종이 여행 일지**에 소중히 기록하므로, 개인적인 생각과 감정이 외부에 노출될 염려가 전혀 없습니다.
- **새로운 마을 개방 축하 연출**:
  - 한 마을의 질문 10개를 모두 완주하면 축하 메시지와 함께 다음 마을의 문이 열리며, 캠핑카가 새로운 마을로 나아가는 성취의 기쁨을 선사합니다.

## 🛠️ 비개발자를 위한 초간단 수정 가이드

### 1. 질문 내용을 고치고 싶을 때
- **수정 파일:** `data/questions.js`
- 파일을 열어 따옴표 안에 적힌 질문 문구를 원하는 대로 수정하고 저장하면 웹 브라우저에 바로 반영됩니다.

### 2. 마을 순서나 보상, 축하 문구를 바꾸고 싶을 때
- **수정 파일:** `js/rules.js`
- `villageOrder`: 마을 순서 변경
- `rewards`: 질문 완료 시 주는 코인이나 기름 수치 변경
- `messages`: 화면에 뜨는 축하 문구 변경

### 3. 요정 모아의 계절이나 이미지를 바꾸고 싶을 때
- **수정 파일:** `js/fairy.js`
- **이미지 파일 교체:** `assets/moa/` 폴더 안의 이미지 파일을 동일한 이름으로 교체하면 됩니다.
